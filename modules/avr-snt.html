• ЭАВР (Акт выполненных работ)
Портал: e-contract.kz
Формат: awpContainer XML
Статусы: PRIMARY / ADDITIONAL
Коды работ: ГСВС (Государственная статистика видов услуг)
Подписанты: Исполнитель (sender) + Заказчик (recipient)
НДС: может быть 0% (освобождено) или 12%
Проводки у получателя (Alpino):
Дт 7210 / Кт 3310 — Затраты на услуги
Дт 1420 / Кт 3310 — НДС к зачёту (если есть)
НУ: 7200Н / 3310Н
• ЭСНТ (Сопроводительная накладная)
Портал: esf.gov.kz
Формат: sntInfoContainer XML
Статусы: DELIVERED → CONFIRMED / REVOKED
Коды товаров: ТН ВЭД (tnvedCode) + TRU Origin
Участники: Продавец (seller) → Грузоотправитель (consignor) → Грузополучатель (consignee) → Покупатель (customer)
Приёмка: acceptanceGoodsInfo — кто принял, дата, доверенность
Проводки у получателя (Alpino):
Дт 1310 (1330) / Кт 3310 — Поступление
Дт 1420 / Кт 3310 — НДС к зачёту
НУ: 1310Н / 3310Н · 1420Н / 3310Н
Ключевые отличия ЭАВР от ЭСФ: ЭАВР — это акт выполненных работ (услуги), ЭСФ — счёт-фактура (налоговый документ для НДС). Они выписываются параллельно. ЭАВР подтверждает факт выполнения работ, ЭСФ — право на зачёт НДС. Оба документа должны совпадать по сумме.
